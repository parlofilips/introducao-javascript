# Atividade Prática: Fundamentos do JavaScript Moderno (ES6+)

**Unidade Curricular:** Programação Front-End  
**Instituição:** SENAI MG  
**Aula 18 (23/11/2026):** Introdução ao JavaScript Moderno: Variáveis, Escopo & Tipos Primitivos  

---

## 🎯 Objetivo da Atividade

Praticar os conceitos fundamentais do JavaScript moderno no navegador:
1. Declarar variáveis aplicando a **regra de ouro da indústria** (`const` por padrão, `let` apenas para valores que mudam).
2. Compreender na prática o **escopo de bloco `{ }`** e observar o erro `ReferenceError` ao tentar acessar variáveis fora de seu escopo.
3. Utilizar o operador unário `typeof` para inspecionar os **tipos de dados primitivos** (`string`, `number`, `boolean`, `undefined`, `null`).
4. Utilizar o **Console das Ferramentas de Desenvolvedor (F12)** como ambiente de testes e depuração.

## 🚀 Como Executar e Testar

1. Abra a pasta do projeto no **VS Code**.
2. Abra o arquivo `index.html` com a extensão **Live Server** (ou clicando duas vezes no arquivo para abrir no navegador).
3. No navegador, pressione a tecla **F12** (ou `Ctrl + Shift + I`) e selecione a aba **Console**.
4. Edite o arquivo `js/script.js` resolvendo os 4 desafios propostos e observe as mensagens sendo impressas no console em tempo real.
